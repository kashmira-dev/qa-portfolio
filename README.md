## 📂 Featured QA Projects

### 1. [SauceDemo E-Commerce Web Application — End-to-End Manual Testing](./manual-testing/bug-reports/saucedemo-test-report.md)
* **Application Under Test:** [SauceDemo](https://www.saucedemo.com)
* **Scope:** Functional, UI, Boundary, and Negative testing across Authentication, Product Catalog, Cart, and Checkout flows.
* **Key Deliverables:**
  * Designed and executed **8 structured test cases** covering positive and negative user journeys.
  * Identified **3 critical/major functional defects** (broken product catalog thumbnails, unresponsive cart removal, and checkout form input overwrite).
  * Configured a custom **Jira Cloud Scrum Board** (`To Do`, `In Progress`, `In QA`, `Done`) and logged detailed bug reports with reproduction steps and visual evidence.
